## Сложности (по кадрам 300 / 1000 / 1700 всех камер)

Белый грузовик на снежной земле — низкий контраст. Кроме того:

* снегопад частицами перед объективом (камеры 5, 9);
* сильная пикселизация и дымка (камера 4), пыль или дым на переднем плане (камера 7);
* грузовик часто за деревьями: камера 6 (кадр 1700), камера 7 (кадр 300);
* грузовик мелкий и далёкий: камера 2 сверху, камера 9 у горизонта;
* камера 2 движется, поэтому вычитание фона базового детектора на ней работает хуже — главная надежда на детектор позы;
* в кадрах камер 1–3 есть огонь или взрыв (в Project 02 его не было) — возможны ложные срабатывания.

Детектор позы обучен на Project 02 (лето, другой ландшафт). На этой сцене возможен заметный провал из-за смены домена.
Первое, что стоит посмотреть после прогона, — долю кадров `tri` и `mono` в `truck_diag.csv` и картинки детекций.

## Прогон на GPU-хосте (4090)

`TRUCK_DEVICE` теперь переводит на видеокарту **все** сети прогона: детектор позы, базовый YOLO-seg и окна yolo11m.
Раньше на GPU шла только поза.

Крупная модель, при 640 (на старых видео она дала там результат лучше, чем при родных 1280):
```bash
TRUCK_WEIGHTS=models/truck_pose_All_yolo11m-pose_1280.pt TRUCK_IMGSZ=640 TRUCK_DEVICE=0 \
  python offline/run.py --data /путь/к/scene2 --out runs/scene2_m640 --objects truck_fused
```

Windows (PowerShell):
```bash
$env:TRUCK_WEIGHTS="models\truck_pose_All_yolo11m-pose_1280.pt"; $env:TRUCK_IMGSZ="640"; $env:TRUCK_DEVICE="0"; python offline\run.py --data C:\Programming\scene2 --out runs\scene2_m640 --objects truck_fused
```

Маленькая модель для сравнения: `TRUCK_WEIGHTS=models/truck_pose_All.pt` без `TRUCK_IMGSZ`.

* Обе модели позы лежат в `models/` в git — достаточно склонировать репозиторий и положить видео.
* Кэш детекций привязан к пути весов и настройкам. Повторный прогон трекера с теми же весами занимает минуты.
* Результат: `<out>/truck.csv` (Unreal, см, `Frame;Loc_X;Loc_Y;Loc_Z`), `<out>/truck_diag.csv`, `<out>/viewer.json`.
  Посмотреть во фронтенде: «Загрузить CSV / SVG» на странице «Траектории».
  Встроенное демо пока жёстко настроено на Project 02 (5 камер `Way1`).
